# ML Data
Die data bestaande uit N=100 is selfgerapporteer d.m.v anonieme lyste, afrondingsfoute kan voorkom en offset is afgekap by 60 minute. Reistyd koloms word nie in die model gebruik nie omdat dit nie die teiken is nie, en dit nie vroeër as die semester vir gebruikers beskikbaar is nie.
Die MAE resultaat hieruit is slegs 'n kruisvalidasie-skatting (om 'n argitektuur keuse te verdedig), en nie 'n onafhanklike validasie nie.
